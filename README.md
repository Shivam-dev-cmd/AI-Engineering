📖 Key Concepts

LLM (Large Language Model)
Neural networks trained on vast text data, capable of understanding and generating human language.

Embeddings
Numerical representations of text that capture semantic meaning in a dense vector space.

RAG (Retrieval-Augmented Generation)
Architecture combining information retrieval with language generation for more accurate, grounded responses.

Vector Database
Specialized database optimized for storing and searching high-dimensional vectors efficiently.

Prompt Engineering
Art and science of crafting effective prompts to get desired outputs from LLMs.
